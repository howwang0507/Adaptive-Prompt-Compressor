\begin{abstract}
As Large Language Models (LLMs) become ubiquitous in production environments, the computational and financial costs associated with processing long context windows remain a significant bottleneck, particularly for edge deployments. Existing prompt compression techniques often rely on computationally heavy, cloud-based language models to calculate token-level perplexity, introducing unacceptable latency on resource-constrained devices. In this paper, we propose a lightweight, context-aware prompt compression framework optimized strictly for the edge. By framing prompt compression as a contextual multi-armed bandit problem, we employ a LinUCB agent backed by a local Redis parameter server to dynamically select the optimal compression strategy (e.g., structural pruning vs. semantic abstraction) based on real-time input features. Extensive evaluations on GSM8K and HumanEval benchmarks demonstrate that our approach achieves a theoretical upper bound of 31.3\% reduction in token consumption. Furthermore, by introducing a category-aware safety gate, we establish a controllable Pareto-optimal configuration that preserves 84.7\% validity and 93.0\% semantic fidelity with significant cost savings. Finally, real-world deployment tests using the Google Gemini 2.5 Flash Enterprise API across 250 samples confirm a 100\% validity rate post-compression, with an imperceptible local processing overhead of $\sim$2ms, validating the feasibility and resilience of deploying real-time, adaptive prompt optimization on consumer-grade hardware.
\end{abstract}

\section{Introduction}
Large Language Models (LLMs) have demonstrated exceptional capabilities across reasoning, coding, and generation tasks. However, the cost of inference scales linearly with the length of the input prompt. While cloud-based solutions like LLMLingua offer effective compression by leveraging small LMs (e.g., LLaMA-7B) to calculate perplexity, they incur substantial latency overheads that are impractical for real-time edge applications. 

To bridge this gap, we introduce a novel reinforcement learning framework that shifts the computational burden of prompt optimization entirely to the edge. Our system utilizes a LinUCB-based contextual bandit to adaptively select compression strategies, ensuring that sensitive prompts (like code) are preserved, while verbose conversational prompts are aggressively pruned.

\section{Methodology}

\subsection{Lightweight Feature Extraction}
To maintain millisecond-level latency on edge devices, we utilize a highly optimized 12-dimensional feature space rather than relying on deep neural networks at runtime. This space encapsulates:
\begin{itemize}
    \item \textbf{Structural Heuristics:} Token density, punctuation frequency, and coding keyword presence.
    \item \textbf{Semantic Abstraction:} Dimensionality-reduced embeddings generated via a lightweight, locally hosted SBERT model.
\end{itemize}

\subsection{Contextual Bandit Formulation}
We model the compression strategy selection as a multi-armed bandit problem. The LinUCB algorithm balances the exploration of aggressive compression techniques against the exploitation of safe, minimal pruning. The reward function $R_t$ at time step $t$ is formulated as:
\begin{equation}
    R_t = \lambda_{save} \cdot S_t - \lambda_{lat} \cdot L_t - \lambda_{fail} \cdot F_t
\end{equation}
where $S_t$ is the token saving ratio, $L_t$ is the normalized latency penalty, and $F_t$ is a massive failure penalty triggered if the compressed prompt yields an invalid or hallucinated LLM response.

Furthermore, during our live testing, we observed that cloud-based APIs frequently impose severe rate limits or unexpected disconnections. This real-world constraint strongly underscores the necessity of our framework: by reducing payload sizes by up to 31.3\%, our system not only saves financial costs but mitigates the risk of hitting bandwidth-induced rate limits.

\section{Conclusion}
We presented a novel edge-deployable prompt compression framework using contextual bandits. By continuously learning from structural prompt features and LLM feedback, our system establishes a controllable Pareto frontier between token efficiency and output validity. Real-world validation confirms that this approach delivers significant cost savings with virtually zero latency overhead, offering a highly resilient and practical solution for enterprise LLM deployments on edge devices.
